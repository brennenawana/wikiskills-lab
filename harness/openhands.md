# Harness: OpenHands (and similar open-source agent platforms)

## Recognize it

- The user says so; its configuration files are present; it runs as a local
  service or container.

## What observation will look like (step 2)

Strong case:

- The platform's own **event log** records agent actions (**measured**).
- The model endpoint is configurable, so model traffic can also run through
  our recording proxy for token and cost ledgers (**measured**).
