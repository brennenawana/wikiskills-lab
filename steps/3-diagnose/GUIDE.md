# Step 3 — Diagnose

**Status: not yet available in this version.** Tell the user so, plainly, and
stop here.

What this step will do: turn the step-2 ledgers into findings, each with its
evidence attached. If the user already knows what they want to improve, their
goal wins. Otherwise this step presents a short ranked list of candidates —
ranked by how measurable the problem is, how much improvement is likely, and
how much effort it takes — each with one paragraph of reasoning. The output is
one chosen focus, written down, that step 4 will build a measuring stick for.
