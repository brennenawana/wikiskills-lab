# Step 4 — Measure

**Status: not yet available in this version.** Tell the user so, plainly, and
stop here.

What this step will do: build the measuring stick with the user — a clear
metric definition, a small test suite drawn from their real work (the frozen
capsules from step 2), scorers that are as mechanical as possible, and
today's baseline score. It also generates the rules of engagement for step 5:
budgets sized to the user's own cost reality, run counts, stop rules, and
escalation rules — presented for approval, never assigned as reading. Nothing
in step 5 runs until the user has approved these rules and seen the baseline.
